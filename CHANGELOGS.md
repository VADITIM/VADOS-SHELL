# Changelogs

Newest version first. The version and its number are set by the user on each push.

## Unreleased

- Every push to master publishes a GitHub release of the version in `shell/config/Release.qml` whose notes are that version's section of this file (`.github/workflows/release.yml`, `tools/release-notes.sh`). A version that already has a release is left alone.

## 0.2.0
- Wi-Fi: networks with a sign-in (WPA-Enterprise, 802.1X, such as school and campus networks) now join with a user name and password. On iwd the shell asks once for admin rights through polkit to save the sign-in for iwd (PEAP with MSCHAPv2); a wrong sign-in asks again and keeps the user name. Without a running polkit agent the page says NO POLKIT AGENT RUNNING.
- Settings > Displays: the REFRESH (HZ) choices show only the number (60, 50); a long list scrolls and drags.
- Settings > Displays: REFRESH (HZ) is a draggable fader over the monitor's refresh rates, showing the number.
- Power page: the three profiles are tinted, PERFORMANCE red, BALANCED blue, POWER SAVER green (glyph and the active dot).
- Widgets: a NOTES widget (4 x 3), a sticky note on the desktop like Windows Sticky Notes. Click it and type; Escape or a click elsewhere stops. The text is kept in `~/.cache/vados/notes.json`.
- Calculator: a small calculator in its own app window, found in the search as Calculator (`ipc call calculator open`). Keyboard and keys, live result, parentheses and percent.
- Settings > Displays: an OUTPUT on/off choice under MONITOR turns a monitor off so it leaves the layout as if unplugged (driftwm writes `enabled = false` in its `[[outputs]]` entry, Hyprland `NAME,disable`); turning it back on docks it at the right of the others. - Taskbar: an expanded idle pill now eases its width back to a circle as it closes instead of snapping.
- Taskbar: a task pill that leaves now eases its length down to a circle, over 210 ms, instead of snapping to it when its last task goes.

- Clipboard history opens over any open menu without closing it (a panel on the overlay layer) and a click anywhere outside it closes it at once.

- Lock screen (contract 6): lock from the power pill, the profile's lock button, `SUPER + L` or `ipc call lock lock`. The taskbar gathers at its power pill, slings to the middle of the screen and bursts into the lock screen's modules (time and date, profile, login window, and the optional weather, music player, mini dashboard and notifications) over your lock background, heavily blurred; a small pill above your picture shows a live call, music, recording or unread notifications. Built on the compositor's session lock (driftwm, Hyprland): a crash keeps the session locked and a restarted shell locks it again; wrong passwords and PAM failures are shown and logged; there is no unlock without the password. After `lock.blankAfter` seconds without input (default 60, set in Customization / Lock Screen) the locked screen switches the displays off and wakes on the next key or move; the desktop itself never blanks or locks on its own. Every screen is locked, the modules sit on the focused one.

Customization / Widgets places them per monitor (MONITOR, then ON/OFF per widget, drag on the screen's grid). `widgets.layout` keeps a layout per monitor name, so a monitor that comes back gets its widgets back; a smaller resolution moves widgets that no longer fit inside. While a fullscreen window covers a monitor its widgets stop updating, and CPU, disk and weather are polled only while a widget shows them.
- Wi-Fi: join secured networks from the Wi-Fi pill. A password prompt grows in the pill (show or hide, Enter, Escape), a refused password asks again, networks with a sign-in ask for a user name and password, OTHER joins a hidden network, and right-click forgets a known one. The password never reaches a command line or disk through the shell.

- The clipboard history cannot be opened while a menu (dashboard, search, settings, notifications) holds the screen.
