# Testing rules

Enforced by `tools/check-rules.py` where marked ✓.

- **Before every commit**: `python tools/check-rules.py` (hard rules, also a Stop hook) and `python tools/tests/run.py` (PySide6; Qt Quick tests in `tools/tests/tst_*.qml`). Both must pass.
- **Every engine has a test** ✓: Liquid, Overlays, Attention, Gesture, Burst, Lifecycle (and `Phases`), Geometry, Toml (the config table edit), Platform, StateFile, Confinement, Schema, Rendering (`LiquidLayer`, `Masked`, `Backdrop`, `config/Rendering.qml`), Lock (the session lock and PAM, on fakes; `tst_lock`, `tst_lockrecovery`), Locking (the lock logic), Log, Supervisor (and `Backoff`), Diagnostics, FrameDebug, Playing, Alerts (the source catalogue), Icons (the icon catalogue), Processes (the task manager logic), Family (the VAD/OS app catalogue), Clipboard (the history logic), Gulp (the landing swell), Throw (the flight progress), Drift (scroll glide), Variation (the procedural burst roll), Placement (the grid maths of the lock screen and the widgets), Widgets (the desktop widget catalogue and per-monitor layouts), Pieces (the settings `Page` and `Piece`: roles, nesting, late pieces, the spread), Calculator (`Arithmetic`, the evaluator and typing rules, and `Builtins`, the in-shell app catalogue; `tst_calculator`), Displays (the output layout maths, config text and keep-or-revert trial) and Features (the registry, the overlay kinds it feeds and the ready budgets; the list is `ENGINE_TESTS` in `tools/check-rules.py`; a new engine joins it).
- **Every singleton service has a preview mock** ✓ (`tools/preview/mocks`), so every module stays previewable.
- **The whole preview loads without a single warning** (`tst_preview.qml`); a warning is a failure.
- **Transitions are tested under rapid input**: toggling a surface faster than its animations must end in a valid phase with nothing orphaned (`tst_burst`), and the move table is fuzzed (`tst_lifecycle`). A leave settled by the watchdog still lands, and leave geometry follows a screen change (`tst_burst`).
- **The frame budget is a test** (`tst_budget`, `rules/performance.md`); a change that pushes the search burst over it fails the suite.
- **A fixed bug gets a test that fails without the fix.** Check that it does by breaking the fix once.
- Fakes for Quickshell types live in `tools/tests/fakes` and follow the real API; when a fake and Quickshell disagree, the fake is wrong.
